## 📌 Projeto em Destaque

### 🧠 Kanban App (inspirado no Trello)

Um projeto full stack focado em experiência real de produtividade e arquitetura moderna.

#### Features implementadas
- ✅ Drag and Drop entre colunas
- ✅ Reordenação dinâmica de cards
- ✅ Persistência inteligente de posição
- ✅ Optimistic UI
- ✅ Cache management com TanStack Query
- ✅ Server Actions
- ✅ Busca global
- ✅ Sistema Inbox
- ✅ Edição inline de títulos
- ✅ Atualizações granulares de dados

#### Em desenvolvimento
- 🚧 Melhorias de UX
- 🚧 Realtime updates
- 🚧 Undo/Redo
- 🚧 Sistema de colaboração
- 🚧 Experiência próxima ao Trello

**Objetivo do projeto:**  
Criar um produto de portfólio que demonstre engenharia frontend moderna e resolução de problemas reais.
